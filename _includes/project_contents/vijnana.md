## Overview

The Vijnana Tech Fest website is a dynamic and user-friendly platform designed to streamline the registration process for candidates and provide easy access to event information. This website ensures a seamless and secure experience for all users through the integration of Google authentication.

## Features

- **Candidate Registration**: Simple and efficient registration process for participants.
- **Event Viewing**: Comprehensive listing and details of all events.
- **Google Authentication**: Secure and seamless user login with Google accounts.
- **Responsive Design**: Optimized for various devices to provide a consistent user experience.

## Tech Stack

- **Frontend**:
  - **React**: For building interactive and responsive user interfaces.
  - **TypeScript**: Ensuring type safety and enhancing code quality.
- **Backend**:
  - **Express.js**: Lightweight and flexible Node.js framework for building the server-side logic.
- **Database**:
  - **MongoDB**: NoSQL database for efficient data storage and retrieval.
- **Cloud Services**:
  - **Various cloud services**: For hosting, storage, and scalability.
- **Authentication**:
  - **Google Authentication**: Providing secure and easy user login.
  - **Firebase**: For authentication and other backend services.

## Project Goals

- To create a streamlined and efficient registration process for the tech fest participants.
- To provide a centralized platform for viewing all event details.
- To ensure a secure and seamless user experience through Google authentication.
